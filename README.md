Smart Bulk Mailer:

A Python-based Email Automation Tool that helps users send emails efficiently to single or multiple recipients. Built with Tkinter for a simple and interactive GUI and SMTP for reliable email delivery. Supports CSV files for bulk emailing and includes a mail counter to track successful sends.

Key Features:

1.Send emails to single or multiple recipients.

2.Upload CSV files for bulk email sending.

3.Interactive GUI with fields for Gmail ID, App Password, Recipient(s), Subject, and Message.

4.Mail counter and error handling for reliability.

5.Modern, responsive design with hover and focus effects.

Technologies Used:

1.Python 3.x

2.Tkinter (GUI)

3.smtplib & email.mime

4.CSV module

How to Use:

1.Run the Python script:

       python email_app.py


2.Enter Gmail ID and App Password.

3.Add a recipient manually or upload a CSV file.

4.Enter the email subject and message.

5.Click Send Email → the app will send emails and display the sent count.

Notes:

1.Use App Passwords for Gmail security.

2.Free Gmail accounts can send up to 500 emails/day.

3.CSV file should have one email per row.

Learning Outcomes:

1.Hands-on experience in Python development, GUI design, and automation.

2.Understanding of SMTP protocol and CSV file handling.

3.Improved productivity by automating repetitive email tasks.
